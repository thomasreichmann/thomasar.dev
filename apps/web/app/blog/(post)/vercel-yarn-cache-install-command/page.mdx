## What the evidence has to be

Timings alone ask the reader to trust someone else's machine. The load-bearing
fact is an integer, printed from the restored build cache before install ran:

```bash
# Install Command set
$ ls .yarn/cache | wc -l
du: cannot access '.yarn/cache': No such file or directory

# zero-config path
$ ls .yarn/cache | wc -l
3552
```

| Resolution |               0.72s |            0.72s |

## The branch

```ts
// packages/next/src/index.ts
if (typeof trimmedInstallCommand === 'string') {
    await execCommand(installCommand, { cwd: entryPath, env: spawnEnv });
} else {
    await runNpmInstall(entryPath, [], { env: spawnEnv }, meta, nodeVersion);
}
```

`runNpmInstall` is where `yarn config set enableGlobalCache false` lives, so the
custom path never runs it, Yarn 4 keeps its packages in `~/.yarn/berry/cache`,
and `prepareCache` uploads an entry for a directory nothing wrote.
